# 姿势矫正规则分析器（P3-2）

目标：为站立位脊柱对齐条目增加规则法分析器，输出保持次数与实时对齐问题，纯逻辑可单测。

范围：`apps/android/` 的 `core/pose/` 与训练页文案；不改后端/契约/小程序。

验收：
- 以肩高差、髋高差、肩髋侧向偏移、头部偏移判定对齐；
- 连续保持 3 秒记一次「保持次数」，偏离后需重新保持；
- 实时输出肩部不平/髋部不平/头部偏移/躯干侧倾；
- 训练页计数标签为「保持次数」，实时提示当前问题；
- JVM 单测覆盖计数、重置、实时问题、阈值边界；`verify_all.py` 通过。
