# 动作幅度自动校准（前 2 次动作学习）

目标：解决全局阈值对个体幅度不适应导致的多计/漏计。

实现：
- `AmplitudeCalibration`：记录前 2 次完成动作的幅度（基线-峰值），取平均。
- 校准完成后，计数进入/退出/达标阈值改为个人幅度的 35%/15%/50%（带下限），覆盖踏步、微蹲、坐位抬腿。
- 校准动作**不计数**，UI 显示「校准中：还需完成 N 次动作」；校准完成后从 0 开始正式计数。
- 工厂 `createExerciseAnalyzer(kind, calibrationReps=2)` 默认开启；单测可传 0 关闭。
- 新增 2 项校准行为测试；Android 127 项通过。

局限：当前每次训练重新校准，未按患者+条目持久化；坐位抬腿仍需膝部入镜，矢状面动作建议侧面机位。
