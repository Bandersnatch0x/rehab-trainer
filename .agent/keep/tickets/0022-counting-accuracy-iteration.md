# 计数准确度迭代（坐位抬腿 / 踏步 / 微蹲）

用户反馈真机计数不准。本轮在规则法内做信号与状态机层面的收敛：

- **坐位抬腿改用膝-髋垂直距离**（原来用踝-髋）：坐姿时膝更靠近躯干、更容易入镜；踝长期不可见是此前漏计主因。
- 前 8 帧取**中位基线**，避免单帧噪声/抬腿中的帧初始化；基线双向慢适应。
- 增加**单次动作最短持续时间 250ms**、**重新武装 200ms**、**两次计数最小间隔**（坐位 500ms / 其他 400ms），过滤抖动连击。
- 坐位抬腿要求回落至基线附近才允许再次计数。
- PoseAnalyzer 每秒日志增加 `wristRaise/hipAnkle`，供按患者实际幅度标定。

验证：Android 125 项单测通过；设备已断开，未做真机复测。
