# 训练记录闭环与演示数据替换（P3-1 收口）

目标：P3-1 剩余部分——训练记录生成/上传，以及首页/记录/预警/档案的演示数据替换（P0-4 前置）。

## 实现

### 训练记录闭环
- `ModelFingerprint`：模型 SHA-256 + 指标算法版本 + 阈值配置版本指纹。
- `SessionRecordBuilder` + `SetOutcome`：每组训练结束组装契约 `SessionRecordCreate`。
- `FileSessionUploadQueue`：按 `clientRecordId` 去重的文件持久化补传队列；临时文件 + rename 原子写入；文件损坏时备份并降级为空队列。
- `ApiSessionSyncService`：批量幂等上传；可重试错误保留并累计尝试次数，业务拒绝（`VALIDATION_FAILED`/`FORBIDDEN`/`NOT_FOUND`）移出队列。
- 训练组结束入队并尽力上传；应用启动与进入记录页补传离线积压。
- 记录页展示「本机还有 N 条待上传」，避免患者以为记录丢失。

### 演示数据替换
- 记录页：`GET /sessions` 真实数据；无有效帧时 `validFrameRatio` 缺失显示「—」而非 0%；存疑状态改为三态（合格 / 存疑 / 未知）。
- 首页：问候语用账号名；训练项目用服务端方案（未绑定时明确标注为内置示例）；连续打卡由真实记录派生。
- 预警：`GET /alerts`；规则码中性映射，未收录的规则码原样回显而不隐藏。
- 档案：`GET /patients/{id}` + 训练记录汇总；只呈现姓名/年龄/机构/训练累计（遵守 D20，不呈现分级与疾病文案）。
- 删除全部 `【演示数据】` 标记与 D21 演示声明。

### 修复
- **时间解析**：服务端以 `to_utc_naive` 存储，回传为无偏移 ISO；原实现只按 `OffsetDateTime` 解析，对每条记录都会失败并回退到原始字符串。现按「带偏移优先、无偏移视为 UTC」解释后转本机时区。
- **对象命名**：`SessionUploads` 同时承担读写入口后更名为 `AppData`，避免名实不符。

## 测试

- 新增 15 项：队列去重与持久化、补传重试/拒绝策略、时间格式化、记录汇总（含连续打卡跨天与脏数据）、档案标题年龄边界。
- Android 单测 150 项 0 失败（原 135）。

## 局限

- 训练累计与连续打卡只覆盖最近 100 条记录（契约 `limit` 上限），非全量历史。
- 记录回读契约不含 `metrics`，因此记录卡片无法显示动作名称；如需按动作统计，须先扩契约。
- 上架/下架后仍无真机端到端复验（当前无设备）。
