# 真机动作识别不可用修复（关键点/机位）

现象：真机上「肩颈牵伸」一直显示“关键点不足”，计数不动。

定位（真机 OPPO PKX110 + logcat 诊断）：
1. 原先只取 `visibility()`，手掌/下肢等被躯干或画面边缘遮挡时 visibility 很低；
2. 传给 MediaPipe 的 timestamp 用微秒（imageProxy 纳秒/1000），不符合“单调毫秒”要求；
3. 检测置信度 0.5、分析分辨率 640×480，远距离/室内光线下检出率低；
4. 可见度硬门槛 0.5，遮挡关键点直接判失败；
5. 保持类动作无实时反馈，用户抬臂时看不到“保持中”；
6. 缺少机位提示，用户距离过近时手臂出框只显示“关键点不足”。

修复：
- `visibility = max(visibility, presence)`；
- 时间戳改为 `SystemClock.elapsedRealtime()` 且严格递增；
- 置信度 0.5→0.35；分析分辨率提升到 1280×720；
- 可见度门槛 0.5→0.2（分析器内部）；
- 增加机位提示（过近/过远）与「保持中…」反馈；`POSE_INCOMPLETE` 文案改为可操作提示；
- 保持计时增加 700ms 丢帧容错；放宽 2D 投影下的伸展阈值（肘角 110°、抬升 0.45 肩宽、不对称 0.75）。

验证：真机 logcat 显示肩 1.00、腕 0.86–1.00；单臂上举时正确提示「幅度不足；肘部未伸展；左右不对称」，双臂上举显示「保持中…」。单测 120 项通过。
