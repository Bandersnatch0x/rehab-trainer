# 术语表

领域词汇的唯一权威。产出的票标题、规格、测试名一律使用此表术语。

| 术语 | 定义 | 备注 |
| --- | --- | --- |
| H-Y 分级 | Hoehn-Yahr 分期,帕金森病运动症状严重度的五级评定 | 本系统按 1–5 级建档;3–4 级为安全逻辑的主要分界;5 级仅宣教与转诊,不进训练流程 |
| 分期确认 | 由康复治疗师对患者 H-Y 分期作出的权威判定 | 未经确认的分期标记为「疑似」,不得用于高风险训练准入 |
| 训练条目 | 一条可执行的训练内容,含视频、节拍、时长、频次、禁忌与适用分级 | 数据实体 `Exercise` |
| 训练大类 | 训练条目的顶层分类:牵伸放松、肌力维持、节律步态、姿势矫正 | 四条固定,不随内容扩展而增加 |
| 处方 | 康复治疗师为单个患者开具或调整的训练安排,引用训练条目并设定组数、次数、节拍与有效期 | 数据实体 `Prescription`;基础方案由系统按分期自动匹配,治疗师在其上增删条目或调整剂量 |
| 训练记录 | 患者完成一次处方训练的结果,含打卡、姿态指标、动作错误次数、中断次数、有效帧占比与算法版本 | 数据实体 `SessionRecord`;版本不一致的记录不得直接比较趋势 |
| 节律性听觉刺激 | 以固定节拍的听觉提示引导步态节律的干预手段 | 缩写 RAS;对冻结步态有循证依据,是本系统的核心机制 |
| 冻结步态 | 行走时突然无法迈步的短暂发作 | 缩写 FOG;自动检测为研究级难题,本系统不做自动检测 |
| 动作计数 | 由关键点序列判定动作完成次数 | 需多信号交叉验证,单看脚踝会产生假阳性 |
| 步态指标 | 由关键点序列推算的步频、步幅、对称性等量化指标 | 供康复治疗师与照护管理员看趋势,不作单次结论 |
| 姿势矫正 | 将患者关节角度与标准动作模板比对并输出偏差 | 姿态识别在本系统唯一不可替代的用途 |
| 康复治疗师 | 确认患者 H-Y 分期、开具与调整处方、审核高风险训练准入的临床角色 | 处方权的唯一持有者;系统自动匹配的方案是其起点而非终点 |
| 照护管理员 | 机构侧账号,查看名下患者档案与预警、登记随访、管理权限 | 仅能查看自己负责的患者 |
| 风险预警 | 由症状自评达到阈值触发的安全事件,含弹窗、语音停止提示、推送与日志 | 触发规则与阈值须经临床签核 |
