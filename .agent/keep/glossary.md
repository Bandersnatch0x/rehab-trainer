# 术语表

领域词汇的唯一权威。产出的票标题、规格、测试名一律使用此表术语。

| 术语 | 定义 | 备注 |
| --- | --- | --- |
| H-Y 分级 | Hoehn-Yahr 分期,帕金森病运动症状严重度的五级评定 | 本系统按 1–5 级建档;3–4 级为安全逻辑的主要分界 |
| 训练条目 | 一条可执行的训练内容,含视频、节拍、时长、频次、禁忌与适用分级 | 数据实体 `Exercise` |
| 训练大类 | 训练条目的顶层分类:牵伸放松、肌力维持、节律步态、姿势矫正 | 四条固定,不随内容扩展而增加 |
| 处方 | 医生为单个患者开具的训练安排,引用训练条目并设定组数、次数、节拍与有效期 | 数据实体 `Prescription`;系统不生成、不推荐处方 |
| 训练记录 | 患者完成一次处方训练的结果,含打卡与姿态指标 | 数据实体 `SessionRecord` |
| 节律性听觉刺激 | 以固定节拍的听觉提示引导步态节律的干预手段 | 缩写 RAS;对冻结步态有循证依据,是本系统的核心机制 |
| 冻结步态 | 行走时突然无法迈步的短暂发作 | 缩写 FOG;自动检测为研究级难题,本系统不做自动检测 |
| 动作计数 | 由关键点序列判定动作完成次数 | 需多信号交叉验证,单看脚踝会产生假阳性 |
| 步态指标 | 由关键点序列推算的步频、步幅、对称性等量化指标 | 供医生看趋势,不作单次结论 |
| 姿势矫正 | 将患者关节角度与标准动作模板比对并输出偏差 | 姿态识别在本系统唯一不可替代的用途 |
