# 用户操作手册

**本文档面向谁**：患者、照护者、康复治疗师、机构管理员。

**不覆盖什么**：部署与运维见 `operations-manual.md`；交付范围、验证证据与临床签核见 `acceptance-report.md`；开发接口与内部实现不在本文范围。

## 1. 先读：当前交付版能做什么

本版是演示交付版。页面标注「演示数据」的内容是界面占位，不代表真实患者或真实训练结果。部分流程已接真实后端，部分仍为演示；请先按下表确认可用范围。

| 端 | 已可用 | 演示或未实现 |
| --- | --- | --- |
| 微信小程序 | 绑定、首页概览、训练条目与剂量查看、训练记录、身体感受记录、提醒查看、个人档案 | 训练执行页展示选中条目的名称、分类与剂量，但**不录制、不上传视频、不做云端分析**，也不生成训练记录；提醒只读 |
| Android App | 训练执行页（摄像头姿态计数、组进度、语音与节拍、紧急停止）、设置页三个辅助开关 | 首页、训练记录、提醒、患者档案含演示数据；训练记录不会上传到机构端；离线视频预缓存未启用 |
| Web 后台 | 登录、患者列表与详情、分期确认、处方开具与调整、预警处置、随访台账、科研聚合 | 权限管理页为演示数据；没有用药协同与审计导出界面 |

**安全底线**：训练中出现头晕、胸闷、心慌、呼吸困难或跌倒时，立即停止训练并联系治疗师或拨打急救电话。Android 训练页在任何布局下都保留「紧急停止」按钮。

## 2. 患者与照护者：微信小程序

### 2.1 首次绑定

1. 打开小程序。未绑定时，首页会提示需要绑定，点击「去绑定」。
2. 在绑定页输入机构管理员提供的一次性绑定码，点击「开始绑定」。
3. 预期结果：进入首页，显示本人或所照护患者的训练概览；绑定码被再次使用时，页面提示「绑定码已使用或已过期」。

如果页面显示「进入演示模式」，可用预置演示账号查看示例数据；进入后页面顶部会显示演示数据提示。生产构建应关闭该入口，以机构实际配置为准。

### 2.2 首页

1. 打开首页。
2. 查看「今日打卡」「近 30 天打卡」「连续坚持」三项数字，以及最近三条训练记录。
3. 预期结果：数字按近 30 个自然日统计；今天尚未打卡时，连续天数从昨天计起。

首页下方提供「健康档案」「身体感受记录」「训练记录」「风险预警」四个入口。

### 2.3 查看训练安排

1. 点击底部「训练」。
2. 查看训练条目列表。每条显示训练大类、训练安排（组数、次数、时长或节拍）。
3. 预期结果：
   - 标记「适合您」的条目可以点击「开始训练」。
   - 标记「需治疗师确认」或「暂未开放」的条目不能进入，并显示原因。
   - 未绑定时，页面显示演示条目并标注演示数据。

演示模式下可以打开「演示：解锁全部条目」开关。该开关只用于演示，不得用于真实训练。

### 2.4 训练执行页（小程序）

点击「开始训练」会进入训练执行页。当前版本该页只展示训练前确认清单与安全提示，**不录制视频、不上传视频、不生成训练记录，也没有训练过程中的动作反馈**。页面上的「开始训练」「结束并上传」按钮尚未接入业务逻辑。

### 2.5 查看训练记录

1. 点击底部「记录」，或从首页进入「训练记录」。
2. 查看近 30 天记录。每条记录显示完成次数、动作错误次数、中断次数、有效帧占比、模型版本、指标算法版本、阈值配置版本和存疑标记。
3. 预期结果：
   - 标记「存在疑点」的记录表示数据质量待核实，不影响已完成的打卡。
   - 不同模型、指标算法或阈值配置版本的记录不能直接比较趋势；页面会提示查看每条记录的版本信息。
   - 没有记录时显示空状态提示，不显示伪造数据。

### 2.6 记录身体感受

1. 从首页进入「身体感受记录」。
2. 在文本框中填写今天的活动感受（1 至 1000 字），例如散步是否轻松、练习后是否疲劳。
3. 点击「提交感受记录」。
4. 预期结果：页面显示提交时间；记录保存到机构端，治疗师可在 Web 工作台的患者详情页「身体感受与评估记录」中查看原文。本页只记录文字感受，不计算量表分数，也不给出风险结论。

照护者代操作时，记录会同时保留操作者与患者本人信息。

### 2.7 查看提醒

1. 点击底部「预警」，或从首页进入「风险预警」。
2. 查看与本人或所照护患者相关的提醒，包括级别、触发时间、当前状态和通知进展。
3. 预期结果：小程序内只读；处理与随访登记由照护管理员或康复治疗师在机构端完成。

### 2.8 查看个人档案

1. 从首页进入「健康档案」。
2. 查看近 30 天打卡、连续打卡、今日打卡，以及姓名、出生年份、所属机构、当前记录人。
3. 预期结果：档案页只显示训练统计与基本信息，不显示临床评估内容。

## 3. 患者与照护者：Android App

### 3.1 启动与设备状态

Android 版当前没有登录与绑定界面，按已绑定的演示设备运行。设置页会显示所属机构与设备绑定状态；解除绑定后没有自助重新绑定入口，需要联系机构管理员。

### 3.2 首页

首页显示今日活力打卡、连续坚持天数、今日处方条目和安全提醒。除「开始今日训练」「查看完整处方条目」外，页面上的处方内容标注「演示数据」，不代表真实处方。

### 3.3 训练列表

1. 打开「训练列表」。
2. 查看四类训练：节律步态、牵伸放松、肌力维持、姿势矫正。
3. 预期结果：
   - 前三类可以进入训练执行页。
   - 姿势矫正显示「需治疗师确认分期」，确认前按钮不可用；点击「查看联系治疗师方式」会显示机构与治疗师信息。

### 3.4 训练执行

1. 首次进入时授予摄像头权限。未授权时页面会显示授权按钮。
2. 按页面提示站入画面。需要全身构图的条目会检查脚部是否入镜；脚部不在画面内时计数冻结，并提示调整站位，恢复后自动继续。
3. 训练中查看实时计数、当前组号与总组数、姿态识别状态。
4. 使用底部按钮：
   - 「暂停 / 继续」：暂停或恢复计数与语音。
   - 「完成本组」：结束当前组；完成后进入下一组，全部组完成后提示训练结束。
   - 「紧急停止」：立即退出训练页。
5. 预期结果：计数按姿态识别结果更新；节律步态条目会播放节拍音与语音提示；设置中关闭后训练页默认不播放，训练页内仍可单独打开节拍开关。
6. 当前版本不会把本次训练写成记录并上传到机构端；离开页面后本次计数不保留。

手机竖屏为教学视频在上、实时画面在下；平板横屏为左右分栏；手机横屏和纯实景模式会调整布局，但紧急停止始终可见。

### 3.5 训练记录、提醒与患者档案

这三个页面当前展示演示数据，不代表真实患者记录：

- 训练记录页显示完成次数、动作错误、中断次数、有效帧占比、存疑标记与版本信息。
- 提醒页显示一条演示提醒，并提供「呼叫康复治疗师」按钮；该按钮只打开系统拨号盘，不自动拨出。机构未配置联系电话时，页面提示联系机构。
- 患者档案页显示演示患者的训练统计与鼓励语，照护者绑定按钮为置灰状态。

### 3.6 设置

1. 打开「设置」。
2. 可开关以下三项，设置会保存并在重新打开应用后继续生效：
   - 「RAS 节拍语音与蜂鸣引导」：控制训练页的语音与节拍音。
   - 「按键防颤振动确认」：点击大按钮时触发振动回馈。
   - 「高对比度界面」：切换高对比度配色。
3. 「解除设备绑定」需要二次确认；解除后本机进入未绑定状态，需联系机构获取绑定码。

### 3.7 离线视频

当前版本未启用离线视频预缓存。断网时不能依赖已缓存的训练视频。

## 4. 康复治疗师：Web 后台

### 4.1 登录

1. 打开机构提供的管理端地址。
2. 输入治疗师账号与密码，点击登录。
3. 预期结果：进入「患者工作台」。账号或密码错误时页面显示后端错误；连续失败 5 次后，5 分钟内再次登录会提示尝试次数过多；患者账号登录会进入 403 页面。

### 4.2 患者列表

1. 进入「患者列表」。
2. 使用「H-Y 分级」和「确认状态」筛选。
3. 查看患者编号、姓名、年龄、H-Y 分级、分期确认状态、跌倒风险、建档时间。
4. 新建患者（照护管理员与康复治疗师可用）：点击「新建患者」，填写姓名（必填）、出生年份与备注（可选），点击「创建档案」。
5. 预期结果：
   - 列表按当前登录机构隔离，不提供跨机构切换或检索。
   - 列表一次最多加载 1000 位患者；达到上限时页面会提示用筛选缩小范围。
   - 疑似患者显示「分期确认」入口；已确认患者显示「调处方」入口。
   - 新建患者建档后为 H-Y 1 期、状态「疑似待确认」，需治疗师完成分期确认（D11）。

### 4.3 患者详情

1. 在患者列表点击「详情」。
2. 查看基本信息、当前有效处方、最近训练记录，以及「身体感受与评估记录」。
3. 预期结果：
   - 当前有效处方显示版本、训练条目、有效期和签发治疗师。
   - 最近训练记录最多显示 100 条，包含完成次数、动作错误、中断次数、有效帧占比、存疑标记和算法版本。
   - 身体感受与评估记录显示记录时间、量表、分值、记录人与内容；量表分界值待临床签核，页面不输出风险分级。

### 4.4 确认分期

1. 从患者列表或患者详情进入「分期确认」。
2. 选择 H-Y 1–5 级。
3. 填写临床查体与评定意见。页面预填了一段示例文本，签发前必须按实际查体结果改写。
4. 点击「签发分期确认」。
5. 预期结果：页面提示签发成功，患者档案的分期确认状态更新为「已确认」；该患者的高风险训练条目与处方准入随之开放。照护管理员看不到该入口，直接访问会被拒绝。

H-Y 5 级只做宣教与转诊，不分配训练方案；后端会拒绝为 5 级患者开具处方。

### 4.5 开具与调整处方

1. 从患者列表或患者详情进入「处方开具与调整」。
2. 在「训练条目与剂量」卡片中逐条选择训练条目并填写组数、每组次数、节拍（BPM）、每周频次；可用「添加训练条目」增加条目，用「移除」删除条目（至少保留一条）。
3. 点击「签发并同步处方」。
4. 预期结果：
   - 没有历史处方时新建处方，版本为 `1.0.0`。
   - 已有处方时按当前版本做乐观锁更新，版本递增（如 `1.0.0` → `1.0.1`）。
   - 另一端先更新时，页面提示版本冲突，并载入最新版本供重新确认。
   - 保存失败（例如训练条目读取失败）时不会创建新处方。

所有条目在一次保存中整体提交：未改动的条目保持原剂量。同一训练条目不能重复添加；训练条目必须已发布且适用于患者当前分期，未确认分期时高风险条目不进入处方。

### 4.6 处置预警

1. 进入「预警中心」。
2. 按「全部 / 严重 / 警告 / 提示」筛选，查看患者、触发时间、触发规则、通知渠道和处置状态。
3. 对「待处理」的预警可点击「确认」（表示已知悉）、「登记随访」或「关闭」；状态推进后按当前状态显示剩余可用操作，例如确认后仍可登记随访或关闭。
4. 预期结果：状态与处理人保存到服务端，刷新后仍然保持；「已关闭」的记录不再显示操作按钮。

预警列表一次最多加载 1000 条，达到上限时按患者或状态缩小范围。

### 4.7 随访台账

1. 进入「随访台账」。
2. 查看状态为「已随访」或「已关闭」的预警记录。
3. 预期结果：台账只读；显示处置状态、处理人与处置说明。契约暂无独立的「处置结论」字段，页面不臆造结论。

### 4.8 科研数据

1. 进入「科研数据」。
2. 查看机构聚合画像（真实患者数、H-Y 分布、分期确认状态分布、年龄分段）和训练数据质量（记录数、存疑比例、有效帧占比分布、版本分布）。
3. 预期结果：
   - 只统计本机构真实数据，演示数据不计入。
   - 样本数小于 5 的单元格显示「—」，不显示 0。
   - 不提供行级患者数据下载或跨机构检索。

### 4.9 权限管理

「权限管理」页当前为演示页面：账号名册为示例数据，页面按钮不执行账号开通或权限变更。不要把它当作真实账号管理入口。

## 5. 机构管理员：Web 后台

机构管理员使用与治疗师相同的登录入口，可以：

- 查看患者列表与患者详情。
- 查看并处置预警、查看随访台账。
- 查看科研数据。
- 查看权限管理页（演示数据）。

机构管理员**不能**确认分期或开具处方；这些入口不会显示，直接访问会被拒绝。当前交付版没有患者建档界面，患者数据需由后端预置或通过接口写入。

## 6. 安全与异常处置

| 情况 | 处理 |
| --- | --- |
| 训练中出现头晕、胸闷、心慌、呼吸困难或跌倒 | 立即停止训练；使用 Android 训练页「紧急停止」；联系治疗师或拨打急救电话 |
| 小程序训练执行页没有录制或上传 | 当前版本未实现该能力；不要把它当作已完成的训练记录 |
| Android 训练后机构端看不到记录 | 当前版本不会上传训练记录；需等待后续版本或由机构另行登记 |
| 绑定码无效、已使用或过期 | 联系机构管理员重新生成一次性绑定码 |
| 登录提示尝试次数过多 | 等待 5 分钟后重试，或联系机构管理员 |
| 处方保存提示版本冲突 | 页面已载入最新版本，确认内容后重新提交 |
| 训练记录标记「存在疑点」 | 数据质量待核实，不影响打卡；由治疗师在机构端查看 |

## 7. 常见问题

**问：患者端为什么只显示训练统计？**
答：临床评估信息只在机构端与治疗师工作台可见，患者端只保留训练统计与基本信息。

**问：小程序能开始训练吗？**
答：可以进入训练执行页查看训练前确认与安全提示，但当前版本不录制、不上传、不生成记录。

**问：Android 训练记录为什么没有出现在机构端？**
答：当前版本 Android 训练执行页不上传记录；机构端展示的是后端已有的训练记录。

**问：管理端为什么没有「新建患者」按钮？**
答：当前交付版未提供管理端建档界面；患者数据需由后端预置或通过接口写入。

**问：科研页的数字为什么显示「—」？**
答：样本数小于 5 的单元格会被抑制，避免从聚合数据反推个人。

**问：权限管理页能开通账号吗？**
答：不能。该页是演示页面，账号开通需由机构按实际账号管理流程处理。
