- 版本：v1.0

- 用途：让客户按“端 × 功能”核对当前演示交付版的实际能力，避免把演示数据、部分实现或范围外能力误读为已交付。

## 1. 状态口径

| 状态 | 含义 |
| --- | --- |
| 已实现 | 当前版本有可运行入口，核心行为已接真实数据或真实业务逻辑，并有可复跑证据。 |
| 演示数据 | 页面与交互存在，但展示内容为 mock/占位，不代表真实患者或真实训练结果。 |
| 部分 | 有入口或部分能力，但缺少关键闭环（例如不录制、不上传、未接真实下发、仅只读），不能按完整功能验收。 |
| 未实现 | 当前版本没有该能力，或只有占位目录/占位页。 |
| 不适用 | 该端不承担此职责，或该功能不属于该端产品边界。 |

**端侧列不要读成“支持/不支持”**：一列写“已实现”只表示该端有真实入口与行为；“部分”表示必须结合“说明/证据”列阅读；“演示数据”不得用于真实业务。

**关键纠正（来自文献预设文档）**：

- Short FES-I ≥11 不等于 full FES-I ≥20；官方分档为 Short 7–8 / 9–13 / 14–28。
- CDC STEADI 2019 已改为二分类；不要把 2017 版三级算法当作 2019 规则。

- HY_SELF 与 RIGIDITY_5 不应被当作诊断分界；前者只做复核触发，后者保持 `None`。
- NRS ≥4 是常用中度疼痛界值，不是运动停止阈值；运动停止规则见安全底线。

## 6. 读表提示

1. **“部分”不是“基本可用”**：例如 Android 训练执行有实时计数与规则法达标提示，但记录不上传、姿势矫正尚未接入；小程序训练执行只展示条目，不构成训练闭环。
2. **“已实现”以演示交付范围为限**：Web 预警处置、科研、审计、视频管理接真实后端，但专业阈值、自动预警、真实通知与生产部署仍未完成。
3. **“演示数据”不得用于真实业务**：Android 首页、记录、提醒、档案，以及权限管理页均为示例。
4. **康复数值不是结论**：所有量表分界与预警阈值均为文献预设，待康复签核；签核前不输出风险分级、不自动预警。
5. **端侧功能不对等是当前事实**：设计目标是三端功能清单一致，但演示版实现程度不同；跨端数据闭环尚未形成。
