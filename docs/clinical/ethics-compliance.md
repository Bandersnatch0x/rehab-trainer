- 状态：**要件梳理完成，实际申报未启动**
- 生成日期：2026-11-08
- 适用系统：帕金森病肌肉保护训练系统（H-Y 1–4 进入训练，5 级仅宣教）
- 对应事项：`docs/delivery/next-actions.md` P5-1（伦理审查与知情同意）、P5-4（数据留存与删除）

> 本文是**工程侧整理的要件清单与差距分析**，不是法律意见，也不构成合规结论。
> 法规条文以官方发布文本为准；正式申报前须由机构伦理审查委员会与法务复核。

## 1. 监管属性判定（未决，优先级最高）

**这是整个伦理路径的前置问题**：本系统是否属于医疗器械，决定了走「伦理审查」还是「医疗器械临床试验」两条完全不同的路径。目前**未做分类界定**。

### 1.1 判定依据

| 文件 | 要点 |
| --- | --- |
| 《康复类数字疗法软件产品分类界定指导原则》（2025 年第 27 号） | 属于医疗器械需**同时**具备：软件驱动干预措施、明确的临床预期用途/适应证/禁忌证、基于循证医学与康复医学理论 |
| 同上 | **不属于**医疗器械的情形：仅个人健康管理（健康行为/生活方式）、仅医患沟通平台、仅播放公开音视频的康复内容平台 |
| 同上 | 言语/视觉/听觉障碍康复训练、**运动康复** → 按**第二类**管理 |
| 《人工智能医用软件产品分类界定指导原则》（2021 年第 47 号） | 三要素须同时满足：①处理对象为医疗器械数据 ②核心功能是处理/测量/模型计算/分析 ③用于医疗用途；缺一即不作为医疗器械管理 |
| 同上 | 算法成熟度低且用于**辅助决策**（病灶识别、性质判定、用药指导、治疗计划）→ 第三类；仅做数据处理测量、提供临床参考 → 第二类 |

### 1.2 本系统的判定分歧点

支持「属于医疗器械（二类）」：
- 声称康复训练用途，按 H-Y 分级限定适用范围，有明确适应证与禁忌证字段；
- 摄像头姿态分析输出关节角度、动作计数、幅度校准——属「对数据进行处理、测量」；
- 训练量、BPM、进阶/退阶规则基于康复医学文献。

支持「不属于医疗器械」：
- 不输出诊断、风险等级或治疗建议（`RISK_LEVELS_ENABLED=False`）；
- 示范视频为公开内容播放，不构成「软件驱动干预措施」的强主张；
- 无自适应治疗算法，训练方案由治疗师下发而非软件生成。

### 1.3 需要做的事

1. 向**省级药品监督管理部门**提交**医疗器械分类界定申请**，取得书面界定意见。
2. 若界定为二类：补《医疗器械临床试验质量管理规范》（2022 年第 28 号）要求，走临床试验路径。
3. 若界定为非医疗器械：仍需按第 2–4 节完成伦理审查与个人信息保护合规。

> ⚠️ **在取得界定意见前，不得对外声称「康复治疗」功效**，以免构成未注册医疗器械的宣称。

## 3. 伦理审查申请材料清单

依据 2023 年第 4 号办法**第十八条**，初始伦理审查须提交 11 项。逐项对照本系统现状：

| # | 法定材料 | 本系统现状 | 差距 |
| --- | --- | --- | --- |
| 一 | 研究材料诚信承诺书 | 无 | **需新写** |
| 二 | 伦理审查申请表 | 无 | **需新写**（机构模板） |
| 三 | 研究人员信息、机构资质证明、经费来源说明 | 无 | 需机构提供 |
| 四 | 研究方案、文献综述、临床前数据 | 部分：`docs/clinical/literature-presets.md` 已有 24 条文献 | **需补研究方案**（设计、样本量、终点、统计方法） |
| 五 | 知情同意书 | 无 | **需新写**，见第 4 节 |
| 六 | 生物样本、信息数据的来源证明 | 部分：数据由本系统采集，来源即研究参与者 | 需说明采集范围与合法性基础 |
| 七 | 科学性论证意见 | 无 | 需外部专家出具 |
| 八 | 利益冲突申明 | 无 | **需新写** |
| 九 | 招募广告及其发布形式 | 无 | 需与试点机构共同确定 |
| 十 | 研究成果的发布形式说明 | 无 | **需新写** |
| 十一 | 伦理审查委员会认为需要的其他材料 | — | 视机构要求 |

### 3.1 可适用免除审查的评估

2023 年第 4 号办法**第三十二条**列出 4 类可免除伦理审查的情形。逐条对照：

| 情形 | 是否适用 | 理由 |
| --- | --- | --- |
| （一）合法获得的公开数据，或观察且不干扰公共行为 | 否 | 数据由本系统主动采集，非公开数据 |
| （二）使用**匿名化**信息数据 | **否** | 系统关联患者账号、训练记录与随访，属可识别信息；且涉及敏感个人信息 |
| （三）已有生物样本，用途在知情同意范围内 | 否 | 不涉及生物样本 |
| （四）生物样本库来源的细胞株/系 | 否 | 不涉及 |

> **结论：不适用免除审查，必须走完整伦理审查。** 第三十二条明确要求「不涉及敏感个人信息」，而本系统处理的正是医疗健康信息。

## 4. 知情同意书要件

依据 2023 年第 4 号办法**第三十六条**，知情同意书须包含 12 项。逐项对照：

| # | 法定内容 | 本系统需填写的具体内容 |
| --- | --- | --- |
| 一 | 研究目的、内容、流程、方法、时限 | 待研究方案确定 |
| 二 | 研究者基本信息及机构资质 | 待试点机构确定 |
| 三 | 预期益处、可能的不适与风险 | **须写明**：摄像头采集影像的隐私风险；运动相关的不良事件（跌倒、肌肉酸痛、心血管事件）；本系统**不提供诊断**、不替代医嘱 |
| 四 | 对研究参与者的保护措施 | 停止规则（见 `literature-presets.md` 第 5 节）、急症升级路径、数据加密与访问控制 |
| 五 | 数据与个人资料的使用范围、共享、二次利用、保密措施 | **须明确**：是否用于算法训练、是否共享给第三方、保存期限、删除方式 |
| 六 | 研究参与者的权利 | 自愿参加、**随时无理由退出且不受不公正对待**、知情、保密、补偿、损害时获免费治疗与赔偿、获取新信息、再次签署、获得知情同意书副本 |
| 七 | 参与前、中、后的注意事项 | 训练前评估、着装与场地、不适即停 |
| 八 | 研究者、伦理委员会、出问题时的联系人 | 待填 |
| 九 | 研究时间与参与人数 | 待定 |
| 十 | 研究结果是否反馈 | 须明确个体结果是否反馈及形式 |
| 十一 | 可能的替代治疗及其受益与风险 | 须写明常规康复治疗选项 |
| 十二 | 生物样本相关 | 不适用（不采集生物样本） |

### 4.1 其他法定要求

- **第三十三条**：须获得**自愿签署**的书面知情同意；无书面能力者取得口头同意并留存**录音录像**等过程记录。
- **第三十四条**：无/限制民事行为能力人须取得**监护人书面同意**，并在其可理解范围内告知本人并征得其同意。
- **第三十五条**：须以研究参与者**能够理解的语言文字、视频图像**表述——对老年 PD 患者，书面文本须配大字号与语音版本。
- **第三十七条**：须**逐项说明**，并给予**充分时间**理解后由本人决定签署。
- **第三十八条**：研究内容实质变化、风险实质提高、行为能力等级提高时，须**再次获取**知情同意。系统若调整阈值或新增分析维度，须触发此条。

## 5. 个人信息保护（PIPL）

### 5.1 敏感个人信息的认定

《个人信息保护法》**第 28 条**将「**医疗健康**」列为敏感个人信息，处理须具备「特定的目的和充分的必要性」并采取严格保护措施。

本系统处理的敏感个人信息至少包括：疾病分期（H-Y）、量表评分、训练记录、预警记录、摄像头采集的影像。

### 5.2 强制义务

| 条文 | 义务 | 本系统现状 |
| --- | --- | --- |
| 第 29 条 | 取得**单独同意**（区别于隐私政策的概括同意） | **未实现**。App 无独立同意流程 |
| 第 30 条 | 告知处理敏感个人信息的**必要性及对个人权益的影响** | **未实现** |
| 第 55 条 | 处理敏感个人信息前须做**个人信息保护影响评估（PIA）**并记录 | **未做** |
| 第 56 条 | 评估报告与记录**至少保存三年** | 未做 |
| 第 17 条 | 告知处理者身份、目的、方式、种类、保存期限、行使权利的方式 | 未实现 |

### 5.3 PIA 须覆盖的三要素（第 56 条）

1. 处理目的、方式是否**合法、正当、必要**，对个人权益的影响及安全风险；
2. 保护措施是否**合法、有效**，是否与风险程度**相适应**；
3. 评估报告与处理记录**至少保存三年**。

## 6. 数据留存与删除策略（P5-4）

**当前系统没有任何留存期限与删除机制**。须在研究方案中明确并实现：

| 数据类型 | 建议留存期 | 依据/说明 |
| --- | --- | --- |
| 摄像头原始影像 | **不落盘**（当前实现即如此，须在方案中写明并验证） | 最小必要原则；若确需留存须单独同意 |
| 姿态关键点/角度序列 | 研究期结束后销毁，或匿名化后留存 | 匿名化后可脱离敏感个人信息 |
| 训练记录、量表评分 | 研究期 + 法定年限 | 需与机构病案管理要求对齐 |
| 预警与审计日志 | 至少 3 年 | 第 56 条 PIA 记录要求 |
| 知情同意书原件 | 研究结束后至少 5 年 | 机构伦理委员会通常要求 |

**须实现的机制**（当前均无）：
1. 患者**撤回同意**后的数据处理流程（停止处理 + 删除 + 告知第三方）；
2. **数据导出**（患者查阅、复制本人信息的权利，第 45 条）；
3. **删除**与删除确认（第 47 条）；
4. 留存期限到期**自动清理**的作业。
